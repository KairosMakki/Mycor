# E0503

Channel type mismatch.

- **Severity:** Error
- **Category:** Concurrency

## Example

```myc
fn main() {
    // non-sendable value sent to another thread
}
```

## Message

The compiler reports `E0503` with a precise source span pointing at the offending construct.

## Why

A concurrency or thread-safety error.

This diagnostic guards against the specific problem described by `channel type mismatch`.

## Fix

Ensure values sent across threads are `Send`, shared data is `Sync`, and channel types match.
