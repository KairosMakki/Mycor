# E0400

Unsafe operation outside unsafe block.

- **Severity:** Error
- **Category:** Unsafe code

## Example

```myc
fn main() {
    let p: *mut i32 = 0 as *mut i32;
    *p = 1; // dereference outside unsafe
}
```

## Message

The compiler reports `E0400` with a precise source span pointing at the offending construct.

## Why

An unsafe operation was used incorrectly.

This diagnostic guards against the specific problem described by `unsafe operation outside unsafe block`.

## Fix

Wrap unsafe operations in an `unsafe { ... }` block and uphold the required invariants.
