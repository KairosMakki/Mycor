# E0601

Division by zero in constant.

- **Severity:** Error
- **Category:** Constants and overflow

## Example

```myc
const X: i32 = 1 / 0; // division by zero in constant
fn main() {}
```

## Message

The compiler reports `E0601` with a precise source span pointing at the offending construct.

## Why

A compile-time constant evaluation failed.

This diagnostic guards against the specific problem described by `division by zero in constant`.

## Fix

Fix the constant expression so it evaluates successfully at compile time (no overflow or division by zero).
