# E0701

Conflicting definitions.

- **Severity:** Error
- **Category:** Forward declarations

## Example

```myc
fn foo(x: i32) -> i32;
fn foo(x: i64) -> i64 { x } // signature mismatch
fn main() {}
```

## Message

The compiler reports `E0701` with a precise source span pointing at the offending construct.

## Why

A forward declaration did not match its definition.

This diagnostic guards against the specific problem described by `conflicting definitions`.

## Fix

Make the forward declaration and its definition have identical signatures.
