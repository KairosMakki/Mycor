- **Category:** Syntax

## Message

The compiler reports `E0029` with a precise source span pointing at the offending construct.

The source code could not be parsed as valid Mycor syntax.

This diagnostic guards against the specific problem described by `invalid utf8`.

## Fix

Check the surrounding syntax: missing delimiters, semicolons, or keywords. The compiler points at the unexpected token.
