# E0108

Unknown field.

- **Severity:** Error
- **Category:** Names and modules

## Example

```myc
fn main() {
    println(unknown_name);
}
```

## Message

The compiler reports `E0108` with a precise source span pointing at the offending construct.

## Why

A name, import, or module could not be resolved.

This diagnostic guards against the specific problem described by `unknown field`.

## Fix

Check spelling, imports (`use`), module declarations (`mod`), and visibility (`pub`). The compiler may suggest a similar name.
