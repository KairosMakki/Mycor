# E0201

Cannot infer type.

- **Severity:** Error
- **Category:** Types

## Example

```myc
fn main() {
    let x: i32 = "hello"; // type mismatch
}
```

## Message

The compiler reports `E0201` with a precise source span pointing at the offending construct.

## Why

A type error was found during type checking.

This diagnostic guards against the specific problem described by `cannot infer type`.

## Fix

Make the types agree, add an explicit annotation, or convert with `as`. Check function signatures and generic arguments.
