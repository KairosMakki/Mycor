# E0310

Cannot borrow packed field.

- **Severity:** Error
- **Category:** Ownership and borrowing

## Example

```myc
fn main() {
    let v = Foo { x: 1 };
    take(v);
    println(v.x); // use after move
}
```

## Message

The compiler reports `E0310` with a precise source span pointing at the offending construct.

## Why

A violation of Mycor ownership or borrowing rules.

This diagnostic guards against the specific problem described by `cannot borrow packed field`.

## Fix

Avoid using a value after it has moved; clone or borrow instead. Ensure borrows do not outlive their values and mutable borrows are exclusive.
