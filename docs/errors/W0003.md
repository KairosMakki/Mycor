# W0003

Unused import.

- **Severity:** Warning
- **Category:** Warnings

## Example

```myc
fn main() {
    let unused = 5; // unused variable
}
```

## Message

The compiler reports `W0003` with a precise source span pointing at the offending construct.

## Why

A non-fatal warning about code quality.

This diagnostic guards against the specific problem described by `unused import`.

## Fix

Remove or use the unused item, or prefix intentionally unused bindings with `_`.
