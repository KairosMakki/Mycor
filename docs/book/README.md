# The Mycor Book

Welcome to Mycor. This book takes you from your first program to advanced topics: ownership, generics, concurrency, unsafe code, and the toolchain.

## How to use this book

- New to Mycor? Start with [Getting started](01-getting-started.md).
- Looking up syntax? See the [Language specification](../spec/syntax.md) and [grammar](../spec/grammar.ebnf).
- Hit a compiler error? Run `myc explain <CODE>` or browse `docs/errors`.
- Contributing to the compiler? See `CONTRIBUTING.md` and `docs/design/architecture.md`.
